## 0. 直接回答：到什么层次？

**"随意猜想" ≈ L4 + L5 全部过关 + L6 起步。**

| 结论 | 展开 |
|---|---|
| L4 是**分水岭** | 猜想如果没有"实验前先写下预期数字"这一步，就只是聊天。L4 = 先算后测、账本先行。 |
| L5 必须**亲手走一遍** | 板端的现象（静默失败、量化噪声、层回退、链接坑）在 PC 世界里根本不存在，没走过全链的人对这类现象无从下手。 |
| L6 是**复利** | 每个猜对/猜错都变成词典条目，越攒越快——这就是"随意"二字的来源（词典够大 + 每个方向都能用一个便宜实验切开）。 |
| 天赋成分 | 很少。拆开看全是四件可攒的资产，见下表。 |

**"随意猜想"不是天赋，是四件资产的乘积：**

| 资产 | 是什么 | 本工程里的位置 |
|---|---|---|
| ① 现象词典 | "现象 → 候选原因 → 判别实验"条目的库存 | 本文 §4（起手 17 条，以后自己加） |
| ② 量级账本 | 参数 / MACs / 耗时 / 量化噪声的第一性模型 | 01 文档 Part 2 账本；本文 §2 走查 A |
| ③ 实验成本表 | 每类实验多贵、先做哪个 | 本文 §1（每行都标了耗时） |
| ④ 判据先行纪律 | 实验前写下"应看到的数"，事后对账误差 <20% | §2 三个走查 + §5 循环 |

> 诚实声明：AI 也经常猜错。本工程的 QAT 在 CPU 白跑 84 分钟（忘了设 `device: cuda`）就是例子——
> 但教训被归档成坑位，下一次直接避开。**这个词典的厚度，就是"阅历"本身。**

## 1. 六段阶梯：全部实验/测试总表

等级 = 知识难度 + 深度（在栈里的位置）+ 耗时的综合。先看总览：

| 级 | 名称 | 知识难度 | 深度（在哪一层） | 单次耗时量级 | 一句话考什么 |
|---|---|---|---|---|---|
| L1 | 复现级 | ★ | PC 全栈跑通 | 秒~分钟 | 会跑、会读、对得上数 |
| L2 | 对照级 | ★★ | PC 层 | 分钟~十分钟 | 单变量 + 预测先说 + 对照看数 |
| L3 | 诊断级 | ★★★ | 全栈（现象） | 分钟~小时 | 现象 → ≥2 候选 → 最便宜判别实验 |
| L4 | 定量级 | ★★★★ | 全栈（数字） | 半小时~一天 | 实验前先算预期，误差 <20% |
| L5 | 链路级 | ★★★★★ | PC+量化+NPU+板端 | 天 | 全链闭环，每个环节都有判据 |
| L6 | 设计级 | ★★★★★+ | 任意层 | 复利 | 自己出题、归档、阴性同权 |

### L1 复现级 —— 会跑、会读、对得上数

| 实验/测试 | 内容 | 耗时 | 状态 | 应看到的数（判据） |
|---|---|---|---|---|
| 冒烟训练 `_smoke` | 1 epoch，只证明"管道通" | 0.03 min | ✅ | acc 0.3872 —— **冒烟只看向量对不对，不看分数** |
| 全量训练 `train.py` | 15 epoch 到收敛 | 1.95 min（GPU） | ✅ | best 0.9923 @ E14；末轮 0.9920（与文档一致） |
| 验收套件 `evaluate.py` | 1 万张 + 6 组扰动 + 字体代理 + int8 模拟 | 分钟级 | ✅ | shift 1~4px = 0.991/0.981/0.9239/0.7044；rot ±10° ≈ 0.988~0.991；font 0.9933；int8-sim 0.9921 |
| 手写板自检 `--selftest` | 合成笔迹走整条管线 | 秒级 | ✅ | 线→1（100%）、圆→0、S→5 |
| ONNX 导出+对拍 | opset18、batch=1、逐张喂 | 秒级 | ✅ | max\|torch−onnx\| = 9.5e-6 |

**通过标准**：任一个数字对不上，先查环境/文件版本，而不是怀疑文档。

### L2 对照级 —— 单变量 + 预测先行

| 实验/测试 | 内容 | 耗时 | 状态 | 应看到的数（判据） |
|---|---|---|---|---|
| E1 容量对照 | `conv_channels` 改小/改大，画"容量-精度"曲线 | 每档 1~5 min | ⬜（半：`runs/lean` = (8,16,16) 的 ✅ 数据） | 参数、精度两降；预计 (8,16,16) ≈ 0.986 |
| E2 增广消融 | 注释掉两行增广重训 | 训练 2 min + 评估分钟级 | ⬜ | train acc 会冲到 ~0.999；shift/rot 曲线明显变差 |
| E4 4bit 权重模拟 | `/127.0` 改 `/7.0` | `evaluate --quick` 分钟级 | ⬜ | 掉幅远大于 int8（体验"量化有多疼"） |
| （工程范例）lean 对照 | 减 MACs 假设的一次真实对照实验 | 训练 0.67 min + 编译/板端分钟级 | ✅ | 98.59% / 4.91 ms（→ 促成成本模型，见 §2 走查 A） |

**通过标准**：**每次实验前先在纸上写预期**（E1: 精度掉一点；E2: train acc 涨、鲁棒性掉）；一次只改一个变量。

### L3 诊断级 —— 现象 → 候选 → 最便宜判别实验

| 实验/测试 | 内容 | 耗时 | 状态 | 应看到的数（判据） |

| E5 错例侦探 | `errors.png` 挑 3 张判"为什么错" | 观察 10~30 min | ⬜ | 给出"模糊/歧义/预处理/我也认不出"的明确判断 |

**通过标准**：把 §4 词典任遮一列，你能补出"候选原因 + 判别实验"。

## 2. "随意猜想"拆解：三个真实走查

### 走查 A：板端 10.95 ms，想进 5 ms 以内，往哪打？（猜想→设计→验证全流程）

```
现象（先量化）  10.95 ms/次
词典            "耗时 = 固定开销 + 边际成本"——常见结构，但需要两个点才能分辨
账本            两个数据点在手：1.95M MACs→10.95ms；0.53M→4.91ms
                解方程 → T ≈ 2.6 ms + 4.3 ns × MACs → 边际项 ~8.3 ms（占 76%）
方向            减 MACs（不是先抠代码——2.6 ms 的固定项才是地板）
设计            最便宜判别实验：通道减半重训（0.67 min）→ 编译 → 板端量
判据先行        预测 = 2.6 + 4.3ns × 0.53M ≈ 4.9 ms
实测            4.91 ms ✓（预测误差 ~0.4%）
归档            公式 + "第一杠杆是减 MACs" 进 NPU 文档 §5.4 与 README
```

**关键认识**：全程没有一个"灵感时刻"，全是 数据 → 模型 → 预测 → 实验 → 对账。
"直觉"只是这条流水线跑得快之后的**副产品**。

### 走查 B：换了 mod.a，板端行为没变？（诊断的候选漏斗）

```
现象            烧录成功，但输出与旧模型一模一样
候选（≥2）      ① 固件没重新链接  ② 烧了但没跑（缺 -u）  ③ 串口工具看的是旧日志  ④ 新模型行为本来就相近
最便宜判别      看 build log 有没有 link 一步 + 看 mod.a 时间戳
定位            Copy-Item 保留源文件时间戳 → gmake 判 "up-to-date" → 用的还是旧模型
修复+归档       刷新时间戳再 build；坑位 #8 进文档
```

**关键认识**：好诊断不是"聪明的猜测"，而是**每条候选都配一个 1 分钟能做的判别实验**。

### 走查 C：E04→E05 准确率回跌 0.11%，要处理吗？（不动手也是结论）

```
现象            0.9833 → 0.9822
账本            0.11% × 10000 张 ≈ 11 张 → 在一轮采样的噪声带内
词典            训练曲线看趋势不看单点（E6 立刻回到 0.9875 佐证）
结论            不动。此时乱调参去追 0.1% 才是真正的错误
对照组          train acc 0.9789 < test 0.9920 "更奇怪"？→ 词典：增广让训练样本更难 → 不慌（E2 亲手验证）
```

**关键认识**：能**忍住不动手**，和能出手一样值钱。噪声与信号的分界线，来自账本。

## 3. 能力 → 级别 → 证据（对照表）

| 你想要的能力 | 至少站上 | 在本工程里可考的"证书" |
|---|---|---|
| 看训练曲线不慌 | L3 | 对"回跌 0.1%"与"train<test"给出解释 + E2 消融数据在手 |

> **L4 之前，"猜"是碰运气；L4 之后，"猜"是计算。**

## 5. 复利循环与升段任务

### 5.1 每次实验的固定动作（"猜想-设计-验证"的最小循环）

```mermaid
flowchart LR
  A["现象：先量化成数字"] --> B["候选：词典匹配 ≥2 个原因"]
  B --> C["成本表：挑最便宜的判别实验"]
  C --> D["判据先行：写下预期数字"]
  D --> E["执行 → 对账（误差 <20%？）"]
  E --> F["归档：结论 + 阴性同权"]
  F --> G["词典 +1（复利）"]
  G --> B
```

### 5.2 四条纪律

1. **先量化再猜**：现象必须变成数字（10.95 ms、0.9822、68.63 KB）——模糊描述无法对账。
2. **判据先行**：实验前写下"应看到的数"；对不上账先怀疑自己，再怀疑系统。
3. **挑最便宜实验**：模拟（秒）< 训练（分钟）< QAT（小时）< 编译 < 板端；能 `--quick` 的别跑全量。**实验便宜，才敢乱猜**——把实验做便宜本身就是设计能力。
4. **证据写文件、阴性同权归档**：终端输出不可信（本机铁律），结果全部进 `runs/*.json`；没收益的实验也是数据。
