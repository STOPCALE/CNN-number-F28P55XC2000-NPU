## Block B 手算题（纸上算完给 AI 对账）

- B1. 5×5 输入、3×3 卷积核、stride=1、无 padding：输出多大？这一层（1 通道→1 通道）有几个参数？【§1.4】

- B3. 把 `conv_channels` 改成 `(8, 16, 16)`：逐层算出**总参数量**和**每层输出尺寸**（注意 Flatten 维度会变！）。【§2.8 + 实验 E1】

## Block C 诊断题（现象 → 最可能原因 → 怎么验证）

- C1. 测试集 99.2%，但你手写的"7"总被认成"1"。列出至少 3 个候选原因，并各给一个验证方法（提示：先用右侧 32×32 预览排除数据侧问题）。【§5.5 + §6.3 + 实验 E5】
- C2. 把增广去掉重训后，train acc 涨到 99.9%，但写手写板反而更容易错——为什么？用你 E2 的实验数据（shift/rot 字段）解释。【§4.4 + 实验 E2】
- C3. `evaluate.py` 里平移 +4px 时准确率掉到 70%，但正常用户不会把数字画出画布——这个测试为什么仍然重要？它保护的是哪条设计？（提示：质心居中的意义）【§5.2 + §6.2】
- C4. 某天你换了个网络去编译 NPU，`summary.md` 里 FCONV 显示 `[ ]`（未上 NPU）——你先怀疑哪几个配置/结构问题？怎么一步步定位？【§7.2 + §7.4】
- C5. 手写板概率条上 10 个数字都挤在 0.1 附近、没有明显赢家——最可能的数据侧原因是什么？（不是模型坏了） 【§6.2-6.3】
